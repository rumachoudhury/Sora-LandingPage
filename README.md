# Sora Landing Page

Sora (空) means **“sky”** in Japanese. The name represents openness, calm, and creating room to breathe — ideas that inspired this mindful productivity workspace.

Sora is a calm, mindful productivity workspace designed to help people focus on what matters. It encourages intentional planning, creative thinking, and a more balanced way to organize daily work.

This project was originally created as a static **HTML/CSS/JavaScript** landing page and has been rebuilt as a modern, reusable **Next.js application** while preserving the original visual style and layout.

## ✨ Features

* Responsive design for desktop, tablet, and mobile
* Modern editorial-style landing page
* Reusable React components
* Smooth animations with Framer Motion
* Interactive FAQ accordion
* Newsletter signup interaction
* Mobile-friendly navigation
* Responsive footer and navigation
* CSS-based Hero artwork
* Clean and intentional UI design
* Custom CSS combined with Tailwind CSS
* Accessible semantic HTML structure

## 🛠️ Technologies

* **Next.js**
* **React**
* **TypeScript**
* **Tailwind CSS**
* **CSS**
* **Framer Motion**
* **JavaScript**

## 🎨 CSS Artwork

The Hero artwork is created entirely with **HTML elements and CSS shapes** rather than image files.

Circles, arches, lines, geometric shapes, and other visual elements are created using custom CSS.

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/rumachoudhury/Sora-LandingPage.git
```

### Navigate to the Next.js application

```bash
cd Sora-LandingPage/nextjs-app
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:3000
```

## 🏗️ Build for Production

Create an optimized production build:

```bash
npm run build
```

Then start the production server:

```bash
npm start
```
